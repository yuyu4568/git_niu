# 高频电子线路：第 2 章 高频基础电路笔记

这是根据课堂录音《“指定方向录音 1”-转文本结果》整理的移动端笔记网页，内容覆盖：

- 课程定位与 3–30 MHz 高频范围
- 电感、电容的高频集总参数模型
- LC 串联谐振回路
- LC 并联谐振回路
- 串并联阻抗等效变换
- 变压器、自耦变压器、电容分压耦合与接入系数
- 功率传输、匹配网络与滤波器

0. 课程定位与研究对象

先明确“这门课到底研究什么”，后面所有电路都能挂到收发信机的具体位置。

🔴 核心结论 高频电子线路研究的是无线电通信系统中与高频信号处理有关的基本单元电路，重点对象是发送设备与接收设备。本课程所说“高频”通常指 3～30 MHz 的短波段。

一个典型无线电通信系统由五部分组成：输入变换器、发送设备、传输信道、接收设备、输出变换器。其中只有发送与接收两部分直接涉及高频信号处理。

📌 一句话定位 发送设备把低频信息“搬”到高频载波上发射；接收设备从众多信号中“选”出目标频率并还原信息。选频、放大、匹配、功率传输就是本章的公共基础。

1. 无源集总元件的电路模型与频率特性

谐振回路由 \(L,C\) 构成，因此先要清楚电感和电容在高频下“不是理想元件”，而应使用含损耗的等效模型。

🔴 必记概念：品质因数 \(Q\) \(Q\) 是衡量储能元件质量的指标，定义为储能与耗能之比。它不是固定常数，而是由电路连接方式与损耗电阻决定；串联看电流相等，并联看电压相等。

1.1 电感线圈的高频等效模型

实际电感线圈存在导线电阻、趋肤效应等损耗，可等效为两种形式：

电感高频特性 \[ Z_L=R_0+j\omega L,\qquad Q_0=\frac{\omega L}{R_0},\qquad \varphi=\arctan\frac{\omega L}{R_0} \] \[ Y_L=G_0+\frac{1}{j\omega L}=G_0-j\frac{1}{\omega L} \]
🟠 易错点 电感在串联等效模型中 \(Q_0=\omega L/R_0\)，但若换到并联模型，电导/电阻关系会互换。不要背公式，要记“串联电流相同、并联电压相同”的推导起点。

1.2 电容的高频等效模型

实际电容也存在介质损耗和引线电阻。串联模型中容抗大小为 \(1/(\omega C)\)，但电容阻抗的虚部是负的。

电容高频特性 \[ Z_C=R_0+\frac{1}{j\omega C}=R_0-j\frac{1}{\omega C},\qquad Q_0=\frac{1}{\omega C R_0},\qquad \varphi=-\arctan\frac{1}{\omega C R_0} \] \[ Y_C=G_0+j\omega C \]
🔴 为什么电容可近似为无损元件 电容的空载品质因数通常可达几千到几万，即损耗电阻 \(R_0\) 很小，所以在多数高频工程计算中把电容视为无损元件。电感损耗相对明显，不能忽略。

2. LC 串联谐振回路

串联谐振是“电流最大”的谐振。分析套路固定：先画等效电路 → 写阻抗 → 令虚部为零求 \(\omega_0\) → 求品质因数 → 画特性曲线。

🔴 串联谐振的判定 对串联回路，谐振时 阻抗最小、电流最大。谐振条件不是“感抗最大”，而是 \(\omega L = 1/(\omega C)\)，即电抗虚部为零。

2.2 阻抗与谐振频率

串联谐振回路阻抗 \[ Z=R+j\left(\omega L-\frac{1}{\omega C}\right) \] \[ |Z|=\sqrt{R^2+\left(\omega L-\frac{1}{\omega C}\right)^2} \]

令虚部为零：

谐振条件与谐振频率 \[ \omega_0 L=\frac{1}{\omega_0 C} \quad\Longrightarrow\quad \omega_0=\frac{1}{\sqrt{LC}},\qquad f_0=\frac{1}{2\pi\sqrt{LC}} \]
🔴 两个品质因数 空载品质因数 \(Q_0=\dfrac{\omega_0 L}{R_0}=\dfrac{1}{\omega_0 C R_0}\)；
有载品质因数 \(Q_L=\dfrac{\omega_0 L}{R_0+R_L}=\dfrac{1}{\omega_0 C(R_0+R_L)}\)。
谐振频率与是否接负载无关，仍为 \(1/\sqrt{LC}\)；但接入 \(R_L\) 会增大总损耗电阻，使 \(Q_L\lt Q_0\)。

2.3 阻抗特性曲线

把 \(|Z|\) 化成便于画图的归一化形式。设 \(Q=\omega_0 L/R\)，则：

归一化阻抗 \[ Z=R\left[1+jQ\left(\frac{\omega}{\omega_0}-\frac{\omega_0}{\omega}\right)\right], \qquad |Z|=R\sqrt{1+Q^2\left(\frac{\omega}{\omega_0}-\frac{\omega_0}{\omega}\right)^2} \]
📌 串联谐振特性总结
  • \(\omega=\omega_0\)：\(X=0\)，电路呈纯阻性，\(\varphi=0\)。
  • \(\omega>\omega_0\)：\(X_L>X_C\)，电路呈感性，\(\varphi>0\)。
  • \(\omega<\omega_0\)：\(X_L<X_C\)，电路呈容性，\(\varphi<0\)。
  • 恒压源供电时，谐振点电流最大，\(R_0\) 上电压最大。

3. LC 并联谐振回路

并联谐振与串联谐振对偶：谐振时阻抗最大，两端电压最大。它常用作选频放大器、接收机输入回路的负载。

🔴 并联谐振的判定 对并联回路，谐振时 导纳虚部为零，等效阻抗最大。理想情况下仍满足 \(\omega_0=1/\sqrt{LC}\)；考虑电感串联损耗时，并联谐振频率略低于 \(\omega_0\)。

3.1 两种等效形式

电感既可等效为 \(R_0\) 与 \(L\) 串联，也可等效为 \(G_0\) 与 \(L\) 并联，因此并联谐振回路有两种画法。

3.2 形式 A 的导纳与谐振频率

形式 A 总导纳 \[ Y=\frac{1}{R_0+j\omega L}+j\omega C =\frac{R_0}{R_0^2+(\omega L)^2} +j\left[\omega C-\frac{\omega L}{R_0^2+(\omega L)^2}\right] \]

令虚部为零，可解出并联谐振频率：

并联谐振频率 \[ \omega_p=\sqrt{\frac{1}{LC}-\frac{R_0^2}{L^2}} =\omega_0\sqrt{1-\frac{R_0^2 C}{L}} =\omega_0\sqrt{1-\frac{1}{Q_0^2}} \]
🟠 并联频率为什么不是 \(1/\sqrt{LC}\) 当电感支路是 \(R_0+j\omega L\) 时，谐振频率会因 \(R_0\) 存在而比理想值低。只有 \(Q_0\gg1\)（通常成立）时，才有 \(\omega_p\approx\omega_0=1/\sqrt{LC}\)。

3.3 谐振电阻与品质因数

谐振时回路等效电阻 \(R_p\) 为：

并联谐振电阻 \[ R_p=\frac{R_0^2+(\omega L)^2}{R_0} =R_0\left(1+Q_0^2\right) \overset{Q_0\gg1}{\approx} Q_0^2 R_0 \]

接负载 \(R_L\) 后，总并联电阻 \(R=R_0\parallel R_L\)，有载品质因数：

并联有载品质因数 \[ Q_L=\frac{R}{\omega_0 L}=\omega_0 C R,\qquad \frac{1}{R}=\frac{1}{R_0}+\frac{1}{R_L} \]
🔴 串联/并联 Q 公式对比
  • 串联：\(Q=\dfrac{\omega_0 L}{R}=\dfrac{1}{\omega_0 C R}\)，电抗在分子。
  • 并联：\(Q=\dfrac{R}{\omega_0 L}=\omega_0 C R\)，电阻在分子。
  • 原因：串联支路电流相同，用 \(I^2X/I^2R\)；并联支路电压相同，用 \((U^2/X)/(U^2/R)\)。

3.4 并联阻抗特性

并联归一化阻抗 \[ Y=G\left[1+jQ\left(\frac{\omega}{\omega_0}-\frac{\omega_0}{\omega}\right)\right], \qquad |Z|=\frac{R}{\sqrt{1+Q^2\left(\frac{\omega}{\omega_0}-\frac{\omega_0}{\omega}\right)^2}} \] \[ \varphi=-\arctan\left[Q\left(\frac{\omega}{\omega_0}-\frac{\omega_0}{\omega}\right)\right] \]
📌 串并联谐振对比
项目串联谐振并联谐振
谐振阻抗最小 \(R\)最大 \(R\)
谐振频率\(\omega_0=1/\sqrt{LC}\)高 Q 时 \(\approx\omega_0\)
\(\omega>\omega_0\)感性容性
\(\omega<\omega_0\)容性感性
品质因数\(\omega_0 L/R\)\(R/(\omega_0 L)\)

4. 串并联阻抗等效变换

很多匹配问题可归结为：把一个串联的 \(R_1+jX_1\) 变成一个并联的 \(R_2\parallel jX_2\)，或反过来。关键是“在同一工作频率下，两端口的对外阻抗相等”。

🔴 等效条件 等效不是元件参数相等，而是 AB 两端看进去的复阻抗相等。由于 \(X_L,X_C\) 随频率变化，等效关系只在指定工作频率 \(\omega\) 下成立。

4.1 推导

并联阻抗：

并联支路阻抗 \[ Z_p=\frac{jX_2\cdot R_2}{R_2+jX_2} =\frac{R_2X_2^2}{R_2^2+X_2^2} +j\frac{R_2^2X_2}{R_2^2+X_2^2} \]

与串联形式 \(Z_s=R_1+jX_1\) 对应实部、虚部相等。设 \(Q=R_2/X_2\)（并联支路的品质因数），得到：

串并联等效公式 \[ R_1=\frac{R_2}{1+Q^2},\qquad X_1=\frac{Q^2}{1+Q^2}X_2 \] \[ R_2=(1+Q^2)R_1,\qquad X_2=\left(1+\frac{1}{Q^2}\right)X_1 \]
🔴 高 Q 实用近似（\(Q\gg1\)） \[ R_2\approx Q^2R_1,\qquad X_2\approx X_1 \] 即：并联电阻被“放大”约 \(Q^2\) 倍，而电抗近似不变。这是很多匹配网络和并联谐振回路求 \(R_p\) 的常用结论。
🟠 易错点 \(Q\) 取的是并联支路的 \(R_2/X_2\)，不是任意值。若已知串联支路 \(R_1,X_1\)，可先求 \(Q=\sqrt{R_2/R_1-1}\) 或用 \(\sqrt{R_2/R_1}\)（高 Q 时）。

5. 耦合连接与接入系数

把负载 \(R_L\) 从回路的一部分“折合”到整个回路两端，便于计算谐振回路的等效负载和品质因数。核心工具是接入系数 \(p\)。

🔴 接入系数定义 本讲采用 \(p=\dfrac{\text{变换前匝数}}{\text{变换后匝数}}=\dfrac{N_2}{N_1}=\dfrac{U_2}{U_1}\)。对变压器耦合，\(p=N_2/N_1\)；对自耦变压器，\(p=N_2/(N_1+N_2)\)；对电容分压，\(p=C_1/(C_1+C_2)\)。

5.1 变压器耦合

变压器耦合变换 \[ R_L'=\frac{R_L}{p^2},\qquad G_L'=p^2G_L,\qquad X_L'=\frac{X_L}{p^2},\qquad L_L'=\frac{L_L}{p^2} \] \[ U_1'=\frac{U_2}{p},\qquad I_1'=pI_2 \]

5.2 自耦变压器耦合

自耦变压器接入系数 \[ p=\frac{N_2}{N_1+N_2},\qquad R_L'=\frac{R_L}{p^2} \]

5.3 电容分压耦合

电容分压接入系数 \[ U_1=I\left(\frac{1}{\omega C_1}+\frac{1}{\omega C_2}\right),\qquad U_2=I\frac{1}{\omega C_2} \] \[ p=\frac{U_2}{U_1}=\frac{C_1}{C_1+C_2},\qquad R_L'=\frac{R_L}{p^2} \]
📌 折合规则速记 记住一对“基准量”：\(p=U_2/U_1\)。则电阻、电抗、电感折合到一次侧均除以 \(p^2\)；电导折合到一次侧乘以 \(p^2\)；电压折合除以 \(p\)；电流折合乘以 \(p\)。功率 \(UI\) 保持不变，这正是推导的物理依据。

6. 功率传输、匹配网络与滤波器

谐振回路只是“选频”；把信号有效地从放大器送出去，还要做功率匹配。这直接关系到功率放大器是否安全、输出功率是否最大。

🔴 为什么要匹配 高频功率放大器输出端若负载不匹配，会产生较大反射/驻波，功率不能有效送出，严重时可能烧坏功放管。匹配网络把实际负载变换成功放需要的阻抗，实现最大功率传输并抑制无用频率。

6.1 最大功率传输条件

设源阻抗 \(Z_S=R_S+jX_S\)，负载经匹配网络后呈现 \(Z_{in}=R_{in}+jX_{in}\)。最大功率传输要求：

共轭匹配 \[ Z_{in}=Z_S^* \quad\Longleftrightarrow\quad R_{in}=R_S,\quad X_{in}=-X_S \]

纯电阻源的特例：当 \(R_L=R_S\) 时，负载获得最大功率 \(P_{L,\max}=V_S^2/(4R_S)\)；但此时传输效率只有 50%，另一半功率消耗在源内阻上。

🟠 区分“最大功率”与“最高效率” 共轭匹配使负载功率最大，但效率不一定最高。通信小信号放大追求功率增益，功放级常需折中考虑输出功率、效率、线性与可靠性。

6.2 滤波器与谐振回路的联系

接收机前端从天线接收大量信号，需要在进入放大器前用滤波器/选频回路抑制带外噪声和干扰。

  • 低通/高通/带通/带阻是按频率选择特性分类的四种基本滤波器。
  • LC 谐振回路本身就是一个带通选频网络；串联谐振对目标频率呈现低阻抗，并联谐振对目标频率呈现高阻抗。
  • 实际工程常使用多级谐振回路或集中滤波器（晶体、陶瓷、声表面波 SAW 滤波器）获得更陡峭的矩形系数。
💡 拓展：矩形系数 \(K_{0.1}\) 常定义 \(K_{0.1}=BW_{0.1}/BW_{0.707}\)，即 0.1 电平带宽与 3 dB 带宽之比。\(K_{0.1}\) 越接近 1，选频特性越接近理想矩形。单 LC 谐振回路矩形系数较大，因此高性能接收机常采用多级谐振回路或专用滤波器。
